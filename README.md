# redoc-partner-docs

Small demo: Next.js (App Router) + Redoc rendering a public OpenAPI spec (Swagger Petstore).

Step 1 of the plan: baseline client-side render. Next steps: per-partner themes/configs, spec filtering, performance comparison.

```bash
npm install
npm run dev   # http://localhost:3000
```

Spec: `public/specs/petstore.json` (from https://petstore3.swagger.io/api/v3/openapi.json).
